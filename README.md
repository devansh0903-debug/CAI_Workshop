# CAI Workshop

Starter materials, code examples, and hands-on exercises for the CAI Workshop sessions.

## Overview

This repository contains the code and notebooks used during the workshop. It covers basic setup, practical demonstrations, and lab exercises designed to be run locally.

## Project Structure

CAI_Workshop/
├── data/              # Datasets and sample input files
├── notebooks/         # Jupyter notebooks for exercises
├── src/               # Python source code and scripts
├── requirements.txt   # Python packages list
└── README.md

## Setup

1. Clone the repository:
git clone https://github.com/devansh0903-debug/CAI_Workshop.git
cd CAI_Workshop

2. Create and activate a virtual environment:

On Linux / macOS:
python3 -m venv venv
source venv/bin/activate

On Windows:
python -m venv venv
venv\Scripts\activate

3. Install the dependencies:
pip install -r requirements.txt

## Running the Code

### Jupyter Notebooks
To run the interactive notebooks:
jupyter notebook

Open the notebooks folder from the browser interface to work through the exercises.

### Python Scripts
To run standalone scripts from the command line:
python src/main.py
